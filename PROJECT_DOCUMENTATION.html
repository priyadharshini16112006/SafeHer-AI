1️⃣ Problem Statement

Women's safety remains one of the most critical societal challenges globally. According to NCRB 2023 data, 88 crimes against women are reported every hour in India, yet only 27% of incidents are ever formally reported. Average police response time stands at 18 minutes — far too long in emergency situations.

⚠️ Current Gap
Existing apps are purely reactive — they only respond after an incident occurs. There is no predictive intelligence.
📊 Under-reporting
73% of incidents go unreported due to fear, stigma, and lack of anonymous channels.
🚔 Slow Response
Law enforcement lacks real-time intelligence dashboards for resource pre-deployment in high-risk areas.
🗺️ No Safe Routes
Navigation apps optimize for speed — not for safety, CCTV coverage, or police proximity.
2️⃣ Our Solution — SafeHer AI
Core Idea: SafeHer AI is the first platform that prevents incidents rather than responding to them. It uses AI/ML to predict danger zones 72 hours in advance and gives both women and law enforcement the intelligence to act proactively.
🗺️ Live Safety Heatmap
Interactive Leaflet.js map showing real-time crime density, safe zones, CCTV coverage and police stations with time filters.
🤖 AI Predictive Engine
ML model analyzes 50+ variables to forecast risk zones 72 hours in advance with 94.2% accuracy.
🚨 One-Press SOS
Countdown SOS that auto-broadcasts live GPS location to emergency contacts and nearest police via WebSocket.
🛤️ Safe Route AI
AI scores routes based on CCTV coverage %, police post count, incident history, and lighting data.
👩‍👩‍👧 Community Network
Crowd-sourced safety alerts, likes/shares, Safety Champions leaderboard, and emergency contacts panel.
📊 Analytics Dashboard
Law enforcement view with trend charts, NLP sentiment analysis, time-pattern heatmaps, and area-wise risk scores.

5️⃣ Database — NeDB (Pure JavaScript Embedded Database)
Why NeDB? The original plan used better-sqlite3 (SQLite), but it requires Microsoft Visual Studio C++ Build Tools to compile native bindings on Windows — which were not available. NeDB is a pure JavaScript, file-based embedded database that requires zero native compilation, works on all platforms, and persists data to flat files automatically.
📦 Type
Embedded document store (NoSQL), similar to MongoDB API
💾 Storage
Flat files in backend/data/ directory — one .db file per collection
⚡ Performance
In-memory index for fast queries, auto-persisted to disk
🔧 API Style
Async/Promise-based MongoDB-like API (find, insert, update, remove, count)
