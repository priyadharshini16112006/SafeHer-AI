# SafeHer AI

SafeHer AI is a women safety analytics and emergency response platform designed to provide real-time safety insights, incident tracking, SOS alerting, and safety guidance through an interactive web dashboard.

## Features
- AI-powered safety predictions and risk insights
- Incident reporting and incident registry
- Safety heatmap for risk visualization
- SOS emergency alert flow
- Community safety posts and awareness features
- Firebase-based authentication
- Responsive web dashboard

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: NeDB (local file-based database)
- Authentication: Firebase Authentication
- Real-time updates: Socket.IO

## Project Structure
- app.js - Main frontend logic
- index.html - Dashboard UI
- backend/ - Server, routes, and database logic
- firebase.js - Firebase client configuration
- auth.html, auth.js - Authentication pages
